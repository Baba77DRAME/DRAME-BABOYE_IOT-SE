Réseau Docker : iot-net

Réseau bridge nommé reptiles-iot. Seuls mosquitto, simulator et server en font partie. Le conteneur front n'en a pas besoin : nginx ne fait que servir des fichiers statiques.

Les noms DNS internes : mosquitto, simulator, server. Le simulateur se connecte à mqtt://mosquitto:1883.

Démarrage et ordre des dépendances

mosquitto  →  healthcheck OK  →  simulator (depends_on)
                              →  server    (depends_on)
front      →  (indépendant, démarre immédiatement)

Le healthcheck mosquitto publie un message test toutes les 5 s. Dès que le broker répond, simulator et server démarrent automatiquement.
