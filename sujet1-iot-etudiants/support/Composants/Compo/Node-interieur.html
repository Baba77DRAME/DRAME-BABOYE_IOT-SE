Note Wokwi : le BH1750 n'est pas un composant natif de Wokwi. Dans le simulateur, il est remplacé par un potentiomètre sur GPIO 34 (ADC). Le diagram.json et sketch.ino utilisent cette substitution. Le code production réel (avec BH1750 I2C) est fourni séparément dans node-reel.ino.

Procédure de simulation Wokwi

  1. Aller sur wokwi.com → New Project → ESP32.
  2. Remplacer le contenu de diagram.json par le fichier diagram.json fourni.
  3. Remplacer le contenu de sketch.ino par le fichier sketch.ino fourni.
  4. Cliquer sur Start Simulation.
  5. Observer le moniteur série : des lignes JSON s'affichent toutes les 5 secondes (intervalle réduit pour la démo).
  6. Appuyer sur le bouton vert (reed switch simulé) : un message {"type":"door","state":"open"} s'affiche immédiatement — c'est l'interruption.
  7. Tourner le potentiomètre (lumière simulée) : la valeur lux change au prochain cycle.

Hypothèse : dans Wokwi, les deux DS18B20 retournent des températures simulées indépendantes par défaut. On peut modifier leurs attributs temperature dans le diagram.json pour simuler des scénarios (surchauffe, lampe bloquée).

Fichiers fournis

  • sketch.ino — code Wokwi (potentiomètre pour lumière)
  • node-reel.ino — code production (BH1750 I2C réel)
  • diagram.json — schéma Wokwi complet

Limites et risques

  • Le BH1750 n'est pas simulable nativement dans Wokwi : la substitution par potentiomètre est suffisante pour valider la logique d'interruption et la sérialisation JSON, pas la précision photométrique.
  • En zone TRO (humidité 85 %), prévoir un boîtier ventilé pour l'ESP32 et des sondes DS18B20 en version IP67.
  • GPIO 2 est partagé avec la LED interne sur certaines versions DevKit — vérifier sur la révision utilisée.
