Partie C — Adaptateur MQTT du simulateur

Contrainte absolue

simulator.js et scenarios.js ne sont pas modifiés. L'adaptateur se branche sur l'EventEmitter du simulateur via sim.on('message') et lui envoie les commandes via sim.handleCommand(cmd).

Flux de données

DirectionCheminDescription
Simulateur → Broker sim.on('message') → wrap() → pub() → client.publish() Telemetry, events, heartbeat, ack. Bufférisé si hors ligne.
Broker → Simulateur client.on('message') → sim.handleCommand() Commandes lamp, setpoint, safety_cut, reboot…
Adaptateur → Broker À la connexion : publish availability (28 nodes + site) QoS 1, retain true. Reconstruit l'état connu du broker.
Broker → Tous (LWT) Déconnexion TCP brutale → broker publie le LWT reptiles/v1/site/availability {status: "offline"}, retain true

Vérification simulator.js / scenarios.js

L'adaptateur utilise uniquement l'interface publique du simulateur :

  • sim.on('message', handler) — écoute les messages émis
  • sim.handleCommand(cmd) — transmet une commande reçue par MQTT
  • sim.start(tickRealMs) et sim.stop() — appelés par index.js

Aucune ligne de simulator.js ni de scenarios.js n'est modifiée.
