Configuration — Variables d'environnement

Toutes les variables sont lues au démarrage de l'adaptateur. Aucun credential n'est codé en dur dans le source.

Référence complète

VariableDéfautDescription
MQTT_BROKER mqtt://localhost:1883 URL complète du broker. Préfixe mqtt:// pour TCP, mqtts:// pour TLS, ws:// pour WebSocket.
MQTT_USER simulator Nom d'utilisateur MQTT (doit correspondre au fichier passwd Mosquitto).
MQTT_PASS simulator Mot de passe MQTT. Ne jamais committer la valeur réelle dans le dépôt.
MQTT_CLIENT_ID simulator-main-<hex> Identifiant client. Généré automatiquement si vide. Doit être fixe pour une session persistante (MQTT_CLEAN_SESSION=false).
MQTT_ROOT_TOPIC reptiles/v1 Racine de l'arborescence des topics. Modifier pour changer de version de protocole.
MQTT_CLEAN_SESSION true true = session propre (recommandé avec buffering applicatif). false = session persistante côté broker (nécessite un clientId fixe).
MQTT_KEEPALIVE 60 Intervalle keepalive en secondes. Le broker déconnecte le client si aucun message n'est reçu dans 1,5 × keepalive.
MQTT_RECONNECT_MIN_DELAY 3000 Délai initial de reconnexion en ms (premier backoff).
MQTT_RECONNECT_MAX_DELAY 30000 Délai maximum de reconnexion en ms. Le délai double à chaque tentative jusqu'à cette valeur.
MQTT_BUFFER_MAX 500 Nombre total de messages conservés hors ligne.
60 % = haute priorité (QoS 1 : door, boot, ack, availability).
40 % = basse priorité (QoS 0 : telemetry, heartbeat).
Augmenter si les coupures peuvent durer plusieurs heures.

Fichier .env.example

# ── Broker ───────────────────────────────────────────────────────
MQTT_BROKER=mqtt://localhost:1883
MQTT_USER=simulator
MQTT_PASS=simulator

# ── Identité du client ───────────────────────────────────────────
# Laisser vide pour générer automatiquement : simulator-main-<hex>
MQTT_CLIENT_ID=

# ── Topics ───────────────────────────────────────────────────────
MQTT_ROOT_TOPIC=reptiles/v1

# ── Session ──────────────────────────────────────────────────────
MQTT_CLEAN_SESSION=true
MQTT_KEEPALIVE=60

# ── Reconnexion (backoff exponentiel) ────────────────────────────
MQTT_RECONNECT_MIN_DELAY=3000
MQTT_RECONNECT_MAX_DELAY=30000

# ── Tampon hors-ligne ────────────────────────────────────────────
MQTT_BUFFER_MAX=500

Utilisation

Copier .env.example en .env et renseigner les valeurs réelles :

cp .env.example .env
# éditer .env avec les vrais credentials

Charger le fichier .env avant de lancer le simulateur :

# Avec dotenv-cli (npm i -g dotenv-cli)
dotenv -- node src/index.js --output mqtt

# Ou manuellement dans le shell
export $(grep -v '^#' .env | xargs)
node src/index.js --output mqtt

Le fichier .env est dans .gitignore — seul .env.example est versionné.

Priorité de résolution

  1. Variable d'environnement (process.env)
  2. Valeur par défaut dans le code (opérateur ??)

Il n'y a pas de fichier de configuration JSON/YAML — uniquement des variables d'environnement pour respecter les 12-factor apps.
