Format des messages

Tous les messages sont en JSON UTF-8. Le champ v est la version du format (actuellement 1).

Les champs node, ts, seq sont présents dans tous les messages — ils correspondent exactement aux champs émis par le simulateur.

Champs communs

ChampTypeDescriptionExemple
vintegerVersion du format1
msgIdstring (UUID v4)Identifiant unique du message, ajouté par l'adaptateur MQTT"a3f2c1d0-…"
nodestringIdentifiant du node simulateur"N-DES-01"
zonestringZone du node, déduite par l'adaptateur"DES"
enclosurestring | nullIdentifiant de l'enclos si applicable"DES-01"
tsinteger (ms epoch)Horodatage du device (fourni par le node)1700000000000
serverTsinteger (ms epoch)Horodatage de réception par l'adaptateur MQTT1700000000050
seqintegerNuméro de séquence croissant du simulateur42
typestringType du message"reading"

Message — Boot

Topic : reptiles/v1/nodes/{zone}/{node-id}/events

{
  "v": 1,
  "msgId": "a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c50",
  "node": "N-SOI-01",
  "zone": "SOI",
  "enclosure": "SOI-01",
  "ts": 5200,
  "serverTs": 1700000010000,
  "seq": 1,
  "type": "boot",
  "reason": "power_on",
  "rssi": -45,
  "fw": "1.4.2"
}

Note : ts=5200 signifie que le node n'a pas encore synchronisé son horloge (5,2 s depuis le boot = depuis l'époque UNIX 0). L'adaptateur utilise serverTs comme temps d'affichage. Voir fichier Horodatage.

Message — Alerte

Topic : reptiles/v1/alerts/{zone}/{node-id}

Les alertes sont générées par le serveur sur analyse des mesures, pas directement par le node.

{
  "v": 1,
  "msgId": "b2c3d4e5-f6a7-4b8c-9d0e-1f2a3b4c5d60",
  "node": "N-DES-04",
  "zone": "DES",
  "enclosure": "DES-04",
  "ts": 1700000600000,
  "serverTs": 1700000600000,
  "seq": null,
  "type": "alert",
  "level": "critical",
  "code": "temp_hot_overflow",
  "message": "Point chaud DES-04 dépasse 50 °C (valeur : 52.1 °C)",
  "value": 52.1,
  "unit": "C",
  "threshold": 50
}

Codes d'alerte définis

codelevelDescription
temp_hot_overflowcriticalTempérature point chaud > seuil espèce
temp_cold_underflowcriticalTempérature point froid < minimum nuit
door_open_timeoutwarningPorte ouverte depuis plus de 15 min
probe_disconnectedcriticalSonde retourne -127 (déconnectée DS18B20)
probe_porwarningSonde retourne 85 °C (Power-On Reset DS18B20)
node_offlinewarningNode hors ligne depuis plus de 2 × heartbeatPeriod
battery_lowwarningBatterie < 20 %

Message — Disponibilité (online / offline)

Topic : reptiles/v1/nodes/{zone}/{node-id}/availability — retained, QoS 1.

Online (publié par l'adaptateur au démarrage ou reconnexion) :

{
  "v": 1,
  "node": "N-DES-01",
  "zone": "DES",
  "status": "online",
  "ts": 1700000000000
}

Offline (Last Will publié automatiquement par le broker en cas de déconnexion brutale) :

{
  "v": 1,
  "node": "N-DES-01",
  "zone": "DES",
  "status": "offline",
  "ts": 0
}

Note : le ts du LWT est 0 car le broker ne connaît pas l'heure exacte de déconnexion. Le front utilise l'heure de réception MQTT pour afficher l'heure de passage offline.
