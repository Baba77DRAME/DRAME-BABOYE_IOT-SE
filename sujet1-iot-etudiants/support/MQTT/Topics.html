Version de l'arborescence : v1. Préfixe racine : reptiles/v1.

Les identifiants de nodes sont ceux du simulateur : N-DES-01, N-ROOM-DES, N-DOOR-MAIN, etc.

Zone BAT = bâtiment, utilisée pour les portes sans zone propre.

Structure générale

reptiles/v1/
  nodes/{zone}/{node-id}/telemetry      ← mesures périodiques (lectures capteurs)
  nodes/{zone}/{node-id}/events         ← événements (porte ouverte/fermée, boot)
  nodes/{zone}/{node-id}/heartbeat      ← signal de vie périodique
  nodes/{zone}/{node-id}/availability   ← état online/offline (Last Will + retained)
  nodes/{zone}/{node-id}/cmd            ← commandes vers le node
  nodes/{zone}/{node-id}/ack            ← acquittements depuis le node
  alerts/{zone}/{node-id}               ← alertes émises par le serveur ou le node

Règle de versionnement

  • Le préfixe v1 permet une migration sans interruption : un nouveau front peut s'abonner à v2 pendant que l'ancien continue sur v1.
  • Tout changement de format de message incompatible incrémente la version majeure du topic.
  • Un changement additionnel (nouveau champ optionnel) ne change pas la version.
